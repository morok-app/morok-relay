# Morok Relay

Сервер месенджера Morok. Приймає, зберігає до доставки й передає
зашифровані повідомлення.

Релей навмисно знає про користувачів якомога менше. Він ніколи не бачить
відкритого тексту, не має приватних ключів і не зберігає історію
листування. Зашифроване повідомлення лежить у черзі, поки адресат його не
забере, після чого файл фізично затирається.

**Що вміє**

- Доставка повідомлень: REST + WebSocket
- Федерація: релеї спілкуються між собою, користувачі різних серверів
  пишуть одне одному
- Групи, анонімні листи, «цифровий заповіт»
- morok.email: вхідна пошта з аліасами, шифрування при отриманні,
  вихідна пошта окремим вузлом

**Чого релей не знає**

Вмісту повідомлень. Хто з ким листується — приховано настільки, наскільки
дозволяє доставка: для приватних чатів використовуються одноразові токени,
і релей зберігає лише їхні хеші.

**Свій сервер**

```bash
curl -fsSL https://morok.app/install.sh | bash
```

Скрипт ставить залежності, налаштовує базу, TLS і сервіси.

**Стек**

Python 3.12 · FastAPI · PostgreSQL · Redis · PyNaCl

Локальний запуск і деталі розробки — у `CLAUDE.md`.
